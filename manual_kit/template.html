HAWK 方式・ほかのプロダクトに展開するためのプロンプト集

機能取扱説明書 横展開キット

HAWK で作った「機能取扱説明書」と同じものを、自分のプロダクトでも作るためのプロンプト集です。資料をフォルダに置いて、プロンプトを Claude Code に貼れば、管理シートと取説スライドができます。そのあとは定期巡回で新機能や FAQ の候補が Slack に届き、承認した分だけ取説に入ります。

元になった仕組み HAWK 機能取扱説明書作成 片山更新 2026-10-16

01やりたいこと

作る

資料を全部読ませて、取説を一発で作る

スクショ・操作動画・サンプルレポート・既存資料と、Slack・メール・会議メモをまとめて読み、管理シートと取説スライドを作ります。

回す

管理シートを常に最新に保つ

毎日または毎週、Slack・メール・会議メモ・Drive を巡回し、新機能・仕様変更・新しい質問を拾ってシートに候補として足します。

承認する

入れるかどうかは Slack で決める

候補ごとに Slack に通知が来ます。✅ 入れる／❌ 入れない／✏️ 直して入れる、を押すだけ。承認した分だけ取説が更新されます。

HAWK の実績：2026-10-09 に初版を作り、同じ日に確定版をお客様向けの固定 URL で公開。2026-10-16 時点で機能113行・画面のスクショ付き 81 ページ。月・木の巡回で承認依頼が届き、承認分は自動で下書きに入っています。

02進め方

  1. 人・1〜2時間（大半はスクショ撮影）資料を集めて Drive のフォルダに置き、下の「設定」の空欄を埋める
  2. Claude・1セッション（放置で OK）プロンプト①「初回構築」を貼る → 管理シートと下書き v1 ができる
  3. 人・30分〜シートを見て直し、全件承認して、下書きを作り直して と頼む。「要確認」の質問は開発に聞いて回答を返す
  4. 人の一言マニュアル本番に反映して → お客様用の固定 URL ができる。以後 URL は変わらず中身だけ更新される
  5. Claude・15分プロンプト②「巡回と承認フロー」を貼る → 定期巡回が登録され、1回目が動く
  6. 人・普段Slack の承認依頼に ✅ ❌ ✏️ を押すだけ。急ぐときやスクショ追加は ③ の一言で頼む

場所何を読むか拾うもの
Slack（主）プロダクト用チャンネル（product・社内利用・営業相談など）の全投稿とスレッドリリース告知、「できる／できない」の回答、不具合と回避策
Slack（全体）ワークスペース全体をキーワード検索（DM は除く）ほかのチャンネルで出た仕様の回答、お客様からの質問

会議メモGemini の自動議事録・議事録 Doc（本文にプロダクト名が出るもの）オンボーディング・商談・社内会議の Q&A。行頭が 【取説】 の行は必ず拾う
Drive名前にプロダクト名を含む仕様書・リリースノート仕様の詳細、提供開始日
公開ページ製品サイト、公開ヘルプお客様向けの言い回し

環境（最初に1回）

  • Claude Code on the web（claude.ai/code）で作業する。スキルとスクリプトの置き場に GitHub リポジトリを1つ用意する。
  • claude.ai のコネクタで Slack・Gmail・Google Drive をつなぐ（読み取りと、Slack の承認依頼の投稿に使う）。
  • Google のシートのセルやスライドへの書き込みはコネクタではできないので、gog / gws（Google Workspace のコマンドラインツール）を使う。セットアップは片山のリポジトリ claude-configgggggg の手順を流用できる。認証は自分の Mac 1台だけで取り、出てきた値をクラウド環境の環境変数に入れる（端末ごとに認証しない）。
  • 承認依頼用の非公開チャンネルを作る。Slack コネクタはつないだ本人の名前で投稿するので、承認者がつないだ本人だとメンション通知が鳴らないことがある。チャンネルの通知を「すべての新規メッセージ」にしておく。
  • 承認者の Slack メンバーID を調べる（プロフィール → ︙ → メンバー ID をコピー）。

05Slack に届く承認依頼の見本

C
承認者（Claude が代理投稿）8:53
@承認者 【アルパカ 取説】取り込み候補が 3 件あります。各候補に ✅（入れる）/ ❌（入れない）/ ✏️（直して入れる）を付けてください。次の巡回で ✅ の分だけ下書きに反映します。本番には反映しません。
#1 【新機能】F-RPT-012 レポートの CSV 出力 レポート画面から表示中の期間の数値を CSV でダウンロードできます。 入れ先: 機能一覧（新規） 出典: #alpaca-product 10/15 のリリース告知
✅ 1
#2 【FAQ追加】Q. 配信中のキャンペーンに広告を追加できますか？ A. 現在はできません。新しいキャンペーンとして作成してください。 入れ先: FAQ 新規 Q-071（関連 F-OPS-017） 出典: 10/14 オンボーディング議事録の【取説】行
✏️ 1
#3 【仕様変更】F-OPS-012 日予算の自動調整 旧: 毎朝 3:00 頃に実行 → 新: 毎朝 8:00 に実行 出典: #alpaca-product 10/16 のスレッド
❌ 1
✅ 入れる承認済にして、次の巡回で下書きの新しい版に入る
❌ 入れない差戻しにする。同じ候補は二度と出ない
✏️ 直して入れるスレッドに直した文を書く。その文で入る

何も押さなければ保留になり、次の巡回でもう一度見ます。「1,3 OK / 2 NG」のようなまとめ返信でも通じます。会議中に「これは取説に入れたい」と思ったら、議事録に 【取説】〇〇はできる と1行書いておけば次の巡回で候補になります。

06HAWK で実際につまずいたところ

プロンプトには対策を入れてあります。運用中に変だと思ったらここを見てください。

スライドを手で直すと消える

スライドは管理シートから毎回作り直すので、直接の修正は次の生成で消えます。直すのはシートかスクリプト。

承認済の行を上書きすると履歴が消える

仕様変更は同じ ID で新しい行を足し、承認されたら古い行を「置換済」にします。

追記が 1000 行目に飛ぶ

チェックボックス列があるとシートの追記 API が末尾を誤判定します。行番号を指定して書きます。

伏せ字の漏れ

メールアドレスの一部、薄く表示されたヘッダーの名前、URL の中の ID、ブランドのロゴ、画面下端で見切れた行で漏れました。自動加工のあとに必ず目で見ます。

非公開の画像がスライドに入らない

Slides API は共有されていない Drive 画像を読めません。pptx を経由して取り込みます。

文字起こしの誤変換

「フォーク／ホーク／航空」が HAWK、「予見」が与件、「マジ」がマージン。表記揺れは最初に教えておきます。

資料どうしで「できる／できない」が食い違う

HAWK では初回だけで5件以上。推測で書かずに「要確認」に起票し、開発に聞いて回答を返します。

下書きと本番を取り違える

お客様に渡すのは本番の固定 URL だけ。下書きは版ごとに URL が変わる社内用です。

毎日巡回だと版が増えすぎる

承認が1件以上あった日だけ新しい版を作り、候補がゼロの日は Slack に投稿しません。

Google への書き込みがコネクタでできない

Drive コネクタは読み取り中心で、シートのセルやスライドに書けません。gog / gws を使います。
