# HAWK 週次 提案ステータス エントリの書き方

HAWK営業チームの週次定例に向けて、「提案ステータス」スプレッドシートの**週ごとのタブ**に
今週の商談・アポ内容を記入する作業の標準ルール。ユーザー（片山さん）が実際に手直しした内容から
「望ましい書き方」を抽出したもの。**この文体・粒度を必ず踏襲すること。**

## 対象シート

- 提案ステータス: `1KbOQJCgxaaAzTcQPmOgTjgYl8bCzZrOGyXhKUnK_ESs`
- タブは週ごと（例: `0706週` / `0713週` / `0720週`）。`gog sheets metadata <id>` で gid→タブ名を確認。
- 列構成（ヘッダーは1行目）:
  | 列 | 意味 |
  |----|------|
  | A | クライアント名 |
  | B | 担当（Yuki / Miwa / Tomo など） |
  | C | ステータス |
  | D | Next Action |
  | E | In or Out（流入ソース） |
  | F | 議事録 |
  | G | `{MMDD}週`（今週の活動サマリ） |
  | I | 失注理由（失注時のみ） |
  ※ H列は空け。既存データの最終行の下に追記する。

## 文体・粒度（最重要）

### G列（今週の活動サマリ）
- **「日付(曜) 実施内容 → 結果/所感」** の簡潔な流れ。改行＋`→` で結果や次の含意を書く。
- 既存顧客・休眠先への継続アプローチは先頭に **`[追いかけ]`** を付ける。
- **具体的な数字・温度感を入れる**（例: 「IG/Tikで500万/月ありそう」「工数半分になりそう、期待度高い」）。
- 関係者は通称＋「さん」でシンプルに（例: 「豊野さん」「利光さん経由 春さん」）。
- **書かないこと**: メールアドレス、bounce等の配信メカ詳細、社内オペの細部。
- **推測値を勝手に入れない**（プラン金額・初月額などは、確定情報がなければ書かない）。

良い例（ユーザー実記入）:
- リソクリ: 「7/8 インバウンド問い合わせ → 7/14(火) オンライン説明(w/中西) → 導入合意。IG/Tikの複数管理画面を一元化できることが魅力。工数も半分になりそう、と期待度高い。」
- 京王: 「[追いかけ] エリアターゲティング対応をご報告(7/9案内)。堀内様より前向きなご返信をいただき、社内共有・精査中。」
- UUUM: 「利光さん経由、運用 春さんへHAWKご案内。IG/Tikで500万/月ありそう。…コスト削減に大きな可能性を感じてもらっている。すみやかに導入を目指し、条件や契約面を調整中。」

### C列 ステータス（語彙）
`5_開始` / `4_商談中（先方検討中）` / `3_商談中` / `2_導入決定` / `1_導入済` / `失注`
実態に合わせる（例: 導入合意済＝`2_導入決定`、案内フェーズ＝`5_開始`）。**確信が持てない格付けは記入後に必ず本人へ確認**。

### D列 Next Action
- 具体的な次の一手を短く。必要なら改行 `→ 条件確認` 等で補足。
- **失注でも将来の再アプローチ経路を書く**（例: 電通北海道「OEMチーム(大和田さん)が…動き出しがあればHideさんx大和田さんラインで再度アプローチ」）。

### E列 In or Out（ソースタグ）
既存タグに倣う: `ad_info` / `OEM` / `DOOH`。状態サフィックス可: `OEM_既存顧客` / `OEM_休眠`。
その他: `社内` / `ウェビナー` / `アウトバウンド（メール）`。
※「社内紹介（◯◯）」ではなく `社内` と簡潔に。

### F列 議事録
- 該当議事録Docの**タイトルをクリック可能リンク**で（`=HYPERLINK("<docUrl>","<docタイトル>")`）。
- **無ければ `-`**（空欄にしない）。
- Gemini自動メモよりも、手動でまとめた `議事録_MMDD_◯◯様商談` / `【議事録】◯◯様_まとめ_...` Doc を優先。

## 手順

1. **gog準備**: `bash setup_gog_remote.sh`（`gog` は `$HOME/bin/gog`。`export PATH="$HOME/bin:$PATH"`）。
2. **対象タブ特定**: `gog -a <account> -p sheets metadata <id>` で gid→タブ名。既存行を `sheets get "'<タブ>'!A1:I40"` で確認（最終行・既存の書き方を把握）。
3. **今週の商談を収集**（読み取り専用）:
   - Googleカレンダー: 当該週の商談/アポ（`[オンライン社外]` `往訪` `HAWKご案内/ご説明` 等）。
   - Gmail: 先方とのやりとり、Geminiメモ（`from:gemini-notes@google.com`）。
   - Drive: 手動議事録を `title contains '議事録'` / `'【議事録】'` やクライアント名で検索し、F列リンク用URLを取得。
4. **記入**: `gog sheets batch-update --input=USER_ENTERED --data-json=@payload.json <id>`。
   - payload は `[{"range":"'<タブ>'!A<n>:I<m>","values":[[...]]}]`（H列は空文字）。
   - 事前に `-n`（dry-run）で確認 → `-y` で実行。日本語や `=HYPERLINK` はJSON経由なら安全。
5. **格付けの判断箇所（電通北海道の失注扱い、温度感の微妙なステータス等）は記入後に本人へ明示して確認**。

## 注意
- 「書かないで」と言われた探索フェーズでは記入しない。明示の記入指示があってから書き込む。
- 共有チームシートなので、上書きせず**新規行に追記**。既存行の文体・タグ表記に合わせる。
