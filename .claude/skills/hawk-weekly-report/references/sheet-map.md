## 4. 議事録Docの命名と探し方

命名：`議事録_MMDD_<社名>（<内容>）` が主流。揺れあり（`議事録_2026-07-07_...` / `議事録_<社名>_HAWKご説明_YYYYMMDD` / `【議事録】...`）。

```bash
gog --account yuki.katayama@fout.jp drive ls --all \
  --query "name contains '議事録_0727' and trashed=false" --max 30 -p
```

- `drive search`（全文検索）は精度が低い。**`drive ls --all --query "name contains ..."` を使う。**
- 週の各日付（月〜金＋土日）で回すか、`議事録_07` のように月単位で引いて日付で絞る。
- **同一商談に「（Gemini自動メモ）」版と整形版が併存する。**
  - 整形版：2〜7KB。**議事録列にリンクするのはこちら**
  - Gemini版：15〜60KB。本文を読む一次ソースとして使う

## 5. gog の実務メモ（このタスク固有）

```bash
# 式を保って読む（引き継ぎには必須）
gog --account $A sheets get $SS "0720週!A1:I40" --render FORMULA -p

# 2次元配列で書く
gog --account $A sheets update $SS "0727週!A2:F20" --values-json '[["...","..."]]'

# 複数レンジを1リクエストで
gog --account $A sheets batch-update $SS --data-json '[{"range":"...","values":[[...]]}]'

# タブ追加（--index はゼロ始まり。複製機能は無いので値は自分でコピーする）
gog --account $A sheets add-tab $SS "0803週" --index 3

# リンクの一覧確認
gog --account $A sheets links $SS "0727週!F1:F40" -p
```

- `--input` は既定 `USER_ENTERED`。**`RAW` にすると HYPERLINK が文字列になる。**
- グローバルフラグはサブコマンドの前。後ろは `unknown flag`。
- `sheets tabs` というサブコマンドは無い（`table` と間違えられる）。タブ一覧は `sheets metadata`。
- `--readonly` は実行時フラグとして存在しない。安全側に寄せたいときは `-n` / `--disable-commands`。
