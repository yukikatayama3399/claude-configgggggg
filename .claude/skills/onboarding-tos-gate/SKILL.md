# onboarding-tos-gate: オンボーディング前の利用規約同意チェック

## ルール

**利用規約の同意が取れていない会社とはオンボーディングを進めない。**
同意＝Web申込フォーム（下記 URL）の送信。送信されると
「【HAWK】Web申込リスト」の「申込リスト」タブに行が増える
（シート ID `1VuZS0aUUG5_r7gIttrofpdAWDY0JRQRUSf2n7p6oJmo`）。
同意前はオンボーディングで先方の広告アカウント（Meta／TikTok 等）を HAWK に接続できない。

日程だけ確定して同意依頼を送り忘れると、当日に何もできない。これが防ぎたい人的ミス。

## いつ・何をするか

オンボーディングに関わるやりとり（日程打診・確定・御礼・事前準備・トライアル開始）が出たら:

1. **まず同意の有無を確認する**（読み取り専用）

   ```bash
   python3 onboarding/check_tos.py            # 今日から30日のオンボ予定 × 申込リスト
   python3 onboarding/check_tos.py --days 14
   ```

   - 🚨 未取得 … 申込リストに無い
   - ⚠️ 要確認 … 似た社名しか無い（別会社かもしれない。人に確認）
   - ✅ 取得済み … 社名一致、または先方参加者のメールドメインが申込者と一致

   カレンダーにまだ予定が無い会社（これから日程を打診する会社）は、
   申込リストを直接見る: `gog --account yuki.katayama@fout.jp sheets get 1VuZS0aUUG5_r7gIttrofpdAWDY0JRQRUSf2n7p6oJmo "申込リスト!A1:W"`

2. **未取得・要確認なら、回答の冒頭でアラートを出す**
   例: `🚨 viviON様（10/19 12:00 オンボーディング）は利用規約の同意が未取得です。`

3. **同意依頼メールを用意する**（下のテンプレ）。
   - 日程確定済みなら、日程を確定したスレッドへの返信で単独のお願いメールを送る
   - これから日程を打診するなら、日程打診メールの中に同意依頼を必ず含める
     （「2点のお願い：①利用規約の同意・申込フォーム ②オンボーディング日程」の型）
   - 送信はしない。本文（必要なら Gmail 下書き）までで止めて片山の確認を取る

## 同意依頼メール テンプレ（日程確定済みの会社向け）

`{}` を埋める。宛先・CC は日程を確定したスレッドと同じにする。

```
株式会社{会社名}
{ご担当者}様

お世話になっております。
株式会社フリークアウトの片山です。
重ねてのご連絡となり失礼いたします。

{M/D（曜）HH:MM}〜のオンボーディングに先立ち、
利用規約へのご同意・お申込フォームのご入力をお願いできますと幸いです。

HAWKでは利用規約へのご同意をいただいた後でないと、
御社の広告アカウント（{Meta／TikTok}）とHAWKの接続を行うことができません。
お手数をおかけし恐縮ですが、オンボーディング当日までにご対応いただけますと幸いです。

【利用規約へのご同意・お申込フォーム】
下記URLより、利用規約をご確認のうえお申込フォームへのご入力をお願いいたします。
https://script.google.com/a/macros/fout.jp/s/AKfycbyJo1T-VnUi_uksFJQqNJ9SVrMhFQdF_uQffEbRxN0-WTuF6AhH1V_T_IPHIu-BMuBHlw/exec

・ご契約プラン：「シルバープラン」をお選びいただければ問題ございません
・ご契約形態：「月次契約」をお選びください

※フォーム上は本契約の形式でのお申込みとなりますが、
つなぎ込み日から2週間以内にご解約のご連絡をいただければ、費用は一切発生いたしません。

ご入力いただいた内容は弊社にて確認のうえ、オンボーディングの準備を進めさせていただきます。

なお、利用規約の社内でのご確認などでお時間が必要な場合は、遠慮なくお申し付けください。
その場合はお手数をおかけしますが、オンボーディングを別日にあらためて設定させていただければと存じます。
直前のお願いとなり、ご負担をおかけして大変申し訳ございません。

ご不明点などございましたら、お気軽にお申し付けください。
引き続き、どうぞよろしくお願いいたします。

片山
```

件名（新規メールで送る場合。スレッド返信なら件名は変えない）:

1. `【HAWK】{M/D}オンボーディング前のお願い（利用規約へのご同意）／フリークアウト片山` ← 既定
2. `【HAWK】利用規約へのご同意・お申込フォームのご入力のお願い／フリークアウト片山`
3. `【ご確認のお願い】HAWK利用規約へのご同意について（{M/D}つなぎ込み前）／フリークアウト片山`

## 注意

- 判定は「迷ったらアラート」。取得済みと誤判定するのが一番まずいので、
  部分一致は ✅ にしない（⚠️ で人に確認させる）。
- オンボーディング予定の判定はタイトル頼み（`オンボ` / `ボーディング` / `つなぎ込み`）。
  `[作業]` `社内` `仮/` `候補` `事前` を含む予定は社内準備として除外している。
  社外のオンボ予定にこれらの語を入れると拾われないので注意。
- 申込リストの「無償トライアル」タブは見ていない（同意の証跡として扱うか未確定のため）。
- このリポジトリでは UserPromptSubmit フック（`.claude/hooks/onboarding-tos-guard.sh`）が、
  プロンプトにオンボーディング系の語があると上記チェック結果を自動で差し込む。
