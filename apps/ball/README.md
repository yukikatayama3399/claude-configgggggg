# BALL（使用感プレビュー版）

Slack・Gmail・Messenger・カレンダーを1つにまとめるタスクハブの、**画面と操作だけ**の版。
実データを取り込む:
- **Gmail・カレンダー**: Mac の gog 経由（個人 Mac は `scripts/setup-gog-mac.sh` で BALL 専用に用意）
- **Messenger**: 透明な裏ウィンドウで facebook.com/messages を読む（初回だけ「読み取り画面を見る」でログイン）
- **Slack**: 透明な裏ウィンドウで、BALL の中でログインした Slack（app.slack.com）から読む。自分宛てメンション（7日）と、相手の発言で止まっている DM

- **真ん中の Claude**: Mac に入っている Claude Code（`claude`）を、ボールごとの会話として呼ぶ。いつもの CLAUDE.md・メモリー・スキル（アカウントのスキルも）・ルーティン・コネクタ・gog がそのまま効く

- 左: ボール一覧（番頭・自分ボール・AI 作業中・返事待ち・今日の予定）
- 中: このボールの AI（チャット / メモ）。入力欄は普通のテキスト欄なので Aqua Voice がそのまま入る
- 右: **本物のブラウザ**。Gmail・Slack・Messenger・メルカリなど、どのサイトもログインしたまま開く。ボールごとにタブを覚える。「スレッド」に切り替えると AI の下書きと送信ボタン
- 上の「全体図」でボールの考え方と画面の見方を表示（初回起動時は自動で出る）

## 絶対ルール（送信）

- **片山さん本人が押さない限り、メールも Slack も Messenger も送らない。**
- AI（真ん中の Claude）ができるのは**下書きまで**。他の人に届く操作は、いつもの許可設定で許していても BALL の中では止める（`claude-bridge.js` の DENY）:
  メールの送信・返信・転送、Slack の投稿・リアクション、カレンダーの招待・変更・出欠の返事、Drive の共有、gog / gws の送信コマンド、Slack API への直接投稿。
  gog は `gog-guard.js` を通るので、どう書いても送信系は動かない。
- Gmail の送信は「送信…」→ 宛先・CC・件名の確認 →「この内容で送信」を本人が押したときだけ。
  アプリ本体の画面からしか受け付けず（右のブラウザのページからは呼べない）、それ以外の gog 呼び出しは常に `--gmail-no-send`。
- Messenger は入力欄に入れるまで。送るのは本人の Enter。
- Slack をつなぐときも同じ（下書きまで。投稿は本人のボタン）。
- 例外は、片山さんが自分で設定した定期実行が**自分宛 DM や決まったチャンネル**に投稿するものだけ（リポジトリ直下の CLAUDE.md「送信の絶対ルール」）。

## Mac で動かす

Node.js（v20 以降）が必要。リポジトリのクローン内で:

```bash
cd apps/ball
npm install
npm start
```

初回は右のブラウザで Google・Slack・Messenger に一度ログインする。ログイン状態はアプリ内に保存され、次回から入ったまま開く。
Google のログインを弾かれないように、アプリのブラウザは普通の Chrome と同じ名乗り方（User-Agent）にしてある。

## 真ん中の Claude

- 使うのは Mac の Claude Code。`claude --version` がターミナルで動き、一度ログインしてあれば OK（API キーは要らない。プランの枠で動く）
- 作業フォルダはこのリポジトリのクローン。ここで普段使っている CLAUDE.md・プロジェクトのメモリー・`.claude/skills` が効く。
  **クローンのフォルダで一度 `claude` を対話で起動して「信頼する」を押しておく**（押していないと、このフォルダの設定が読まれない）
- 下の選択:
  - 「いつもどおり」… 普段と同じ道具を全部使う。許可の判断は Claude Code の auto モード（危ない操作は自動で止まる）。送信系だけ止める
  - 「読むだけ」… 読む道具だけ
  - モデル … Opus 5.5 / Sonnet 5.5
- ボールごとに会話が続く（Claude Code の `--resume`）。会話・メモ・下書きはこの Mac の中にだけ保存
- 右の下書き欄に入れるのは Claude の道具 `ball_set_draft`。Gmail の下書きへの保存も送信も、自分のボタン
- 議事録のボールは一番上に「議事録の元」（Gemini のメモ本体）のリンクと「Claude で議事録にする」ボタン。
  いつものスキルの段取り（顧客フォルダの 1_議事録 に格納、フォルダが無ければ作成）で作り、要点とリンクをボールのメモにも入れる
- 下のステータスの「Claude」を押すと、読み込まれたスキル・コネクタと、止めているものが見える
- 環境変数: `BALL_CLAUDE`（claude の場所）、`BALL_CLAUDE_CWD`（作業フォルダ）、`BALL_CLAUDE_MODE`（auto 以外にしたいとき）

## リンクと資料

- メール・Slack・Messenger・予定の説明に出てくるリンクは、名前つきのボタン（「■ お申込フォーム」の下の URL →「📝 お申込フォーム」）。行き先のドメインも出す
- 押すと BALL と同じログインのまま別ウィンドウで開く（Esc で閉じる）。⌘クリックなら右のタブ
- スレッドや予定に出てくる資料（添付・Google のファイル・フォーム）は、上の資料バーに古い順で並ぶ

## Slack

- 自分宛てメンション（7日）と、相手の発言で止まっている DM（30日）をボールにする。
  DM の一覧を取る API が使えない Slack（Enterprise Grid など）では、検索（自分宛て DM と自分の発言）から拾う
- 下書き欄で `@` を打つとメンションの候補が出る（スレッドの人 → チャンネルのメンバー）。↑↓ で選んで Enter / Tab。
  下書きでは「@名前」のまま見せ、送る直前に Slack の本物のメンションに直す。送信の確認に、通知が届く人を出す

## ショートカット

| キー | 動き |
|---|---|
| ⌘1 | 左の一覧を出す / しまう |
| ⌘K | ボールを追加 |
| ⌘L | URL バーへ |
| ⌘T / ⌘W | タブを開く / 閉じる |
| ⌘Enter | AI に送信 |

中と右の境目はドラッグで幅を変えられる。

## ファイル

| パス | 中身 |
|---|---|
| `main.js` | アプリ本体。ウィンドウ、ブラウザの設定、ポップアップをタブで開く処理、リンクの確認ウィンドウ、Claude の道具の中身 |
| `claude-bridge.js` | 真ん中の Claude。Claude Code を呼び、返事を画面へ流す。禁止する送信系の一覧（DENY） |
| `claude-tools.js` | Claude に渡す BALL の道具（下書き欄・メモ・Gmail/カレンダー/Drive/Docs/Sheets）。MCP サーバー |
| `gog-guard.js` | Claude が叩く gog の門番。送信・返信・転送を必ず止める |
| `preload.js` | 画面からアプリ本体を呼ぶ窓口 |
| `renderer/index.html` `styles.css` `app.js` | 画面 |
| `renderer/data.js` | 見本データ。裏側をつなぐとここが実データに置き換わる |
| `scripts/make-preview.js` | ブラウザで見る用の `renderer/preview.html` を作る（`npm run preview`） |

## 次にやること（裏側）

1. Slack・Gmail・カレンダーの取り込み（gog / Slack API）→ `data.js` を実データに
2. Messenger は右のブラウザで開いた messenger.com から未読を読み取る
3. 完了を自動で判定（返信した・送った・予定が終わった）
