# BALL（使用感プレビュー版）

Slack・Gmail・Messenger・カレンダーを1つにまとめるタスクハブの、**画面と操作だけ**の版。
データは見本で、裏側（取り込み・Claude）はまだつないでいない。送信・書き込みは一切しない。

- 左: ボール一覧（番頭・自分ボール・AI 作業中・返事待ち・今日の予定）
- 中: このボールの AI（チャット / メモ）。入力欄は普通のテキスト欄なので Aqua Voice がそのまま入る
- 右: **本物のブラウザ**。Gmail・Slack・Messenger・メルカリなど、どのサイトもログインしたまま開く。ボールごとにタブを覚える。「スレッド」に切り替えると AI の下書きと送信ボタン
- 上の「全体図」でボールの考え方と画面の見方を表示（初回起動時は自動で出る）

## 絶対ルール（送信）

- **片山さん本人が押さない限り、メールも Slack も Messenger も送らない。**
- AI（真ん中の Claude）ができるのは**下書きまで**。AI には送信の手段そのものを渡さない。
- Gmail の送信は「送信…」→ 宛先・CC・件名の確認 →「この内容で送信」を本人が押したときだけ。
  アプリ本体の画面からしか受け付けず（右のブラウザのページからは呼べない）、それ以外の gog 呼び出しは常に `--gmail-no-send`。
- Messenger は入力欄に入れるまで。送るのは本人の Enter。
- Slack をつなぐときも同じ（下書きまで。投稿は本人のボタン）。

## Mac で動かす

Node.js（v20 以降）が必要。リポジトリのクローン内で:

```bash
cd apps/ball
npm install
npm start
```

初回は右のブラウザで Google・Slack・Messenger に一度ログインする。ログイン状態はアプリ内に保存され、次回から入ったまま開く。
Google のログインを弾かれないように、アプリのブラウザは普通の Chrome と同じ名乗り方（User-Agent）にしてある。

## ショートカット

| キー | 動き |
|---|---|
| ⌘1 | 左の一覧を出す / しまう |
| ⌘K | ボールを追加 |
| ⌘L | URL バーへ |
| ⌘T / ⌘W | タブを開く / 閉じる |
| ⌘Enter | AI に送信 |

中と右の境目はドラッグで幅を変えられる。

## ファイル

| パス | 中身 |
|---|---|
| `main.js` | アプリ本体。ウィンドウ、ブラウザの設定、ポップアップをタブで開く処理 |
| `preload.js` | 画面からアプリ本体を呼ぶ窓口 |
| `renderer/index.html` `styles.css` `app.js` | 画面 |
| `renderer/data.js` | 見本データ。裏側をつなぐとここが実データに置き換わる |
| `scripts/make-preview.js` | ブラウザで見る用の `renderer/preview.html` を作る（`npm run preview`） |

## 次にやること（裏側）

1. Slack・Gmail・カレンダーの取り込み（gog / Slack API）→ `data.js` を実データに
2. 中の AI を Claude（Claude Agent SDK）につなぐ。権限は「下書きまで」が既定
3. Messenger は右のブラウザで開いた messenger.com から未読を読み取る
4. 完了を自動で判定（返信した・送った・予定が終わった）
