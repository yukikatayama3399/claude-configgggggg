# HAWK トライアル（配信設計のみ）

展示会リード向けの「高速有償化モデル」用の簡易アプリ（2026-11-10 オフサイト第4部の【確定】事項）。
**トライアルモード＝配信設計まで**。媒体連携ボタンは押せず、代わりに「〇〇までのお申込みで1ヵ月無料（クーポンコード）」を出す。

画面と項目は「HAWK 機能取扱説明書マスター（v1）」のサイトマップ（S-03〜S-13、S-21）と、デモ紙芝居のキャプチャをもとに再現している。

## 流れ

1. **お申込み** `/`: 会社名・氏名・メールを入力（個人情報の利用に同意）→ `data/store.json` に保存。`HAWK_TRIAL_SLACK_WEBHOOK` があれば決まったチャンネルに通知
2. **招待** `/admin?key=…`: 担当者が「招待リンクを発行」→ 招待メールの文面が出る。**アプリは送信しない**。
   `HAWK_TRIAL_GOG_ACCOUNT` があれば「Gmail 下書きを作る」（`--gmail-no-send` 付き）で Gmail の下書きまで作れるので、送信は本人が Gmail で押す
3. **サインアップ** `/signup?invite=…`: パスワード設定と、必須2つ（利用規約／メールアドレス取得・利用）と任意1つ（案内メール）の同意
4. **利用** `/app`: ログイン必須。与件 → オーディエンス設計 → 見積り → 配信設計 → 確認ページ（連携はロック → 本申込みの案内）

## アプリでできること

| 画面 | 中身 |
|---|---|
| 与件一覧 | 検索・新規作成・アーカイブ、行から設計/見積り/配信設計を直接開く |
| 与件詳細 | Notes にメモを貼る → **AI が Details を埋める**（読み取りメモ＝補完した項目と依頼者への確認事項つき）。項目はクリックで編集。追記（「予算は150万に変更」）で差分だけ更新 |
| Meta/TikTok タブ | サンプル広告アカウント・ページ、クリエイティブの選択と新規作成（画像は縮小、動画は先頭コマをサムネイルに） |
| オーディエンス設計 | 狭い／普通／広い の3案（AI が選んだ興味・関心）、推定サイズ、関心の追加・削除、使う案の選択 |
| 見積り | 動画／静止画別の imp・リーチ・クリック・ThruPlay・完全視聴（TikTok は6秒視聴）。CPM・FQ・CTR・率を直すと再計算、KPI との比較、コピー（TSV） |
| 配信設計 | 閲覧モード／編集モード。キャンペーン → 広告セット → 広告。広告セットの複製・分割（性別／年代／配置）・削除、広告の複製・削除、特別な広告カテゴリの制限 |
| 確認ページ | 設定一覧、リンクコピー、印刷/PDF、**「Metaに連携」はロック**＋1ヵ月無料オファー |
| その他メニュー | キャンペーン管理・レポート・ピクセル・ワークスペース設定等は 🔒（正式版でできることを説明して本申込みへ誘導） |

与件・設計データは**利用者のブラウザ（localStorage）にだけ**保存する。サーバーに残るのはアカウントと申込情報だけ。

## AI 読み取り（いちばん大事なところ）

`ai.js` が Mac の Claude Code（`claude -p`）を1回ずつ呼ぶ（BALL と同じ方式。API キー不要、Claude Code のログインで動く）。
`--json-schema` で出力の形を固定し、道具・コネクタは使わせない。メモは「資料」として扱い、中の指示には従わない。

2026-11-10 にチャット・メール・依頼書・会話ログの4パターンで検証済み:
予算（「35万」「月80万×期間」「ネット300万」→ グロス換算）、期間（年なし・「12月頭から年内」）、目的（認知／リード／売上／動画視聴）、
性別・年代（「30〜40代男性」→30〜49）、地域（「首都圏」「関西」→都府県に展開、市区まで）、KPI→入札（CPM300・マージン20% → ¥240）、
特別な広告カテゴリ（不動産 → 住宅）、薬機法に配慮した広告文、依頼者への確認事項まで出る。1回 15 秒前後。

サーバーに AI が無いとき（`index.html` を直接開いた等）は、ブラウザ内の簡易読み取り（正規表現）で動く。精度はかなり落ちる。

## Mac で動かす

Node.js 20 以降と、ログイン済みの Claude Code（`claude` コマンド）が必要。依存パッケージなし。

```bash
cd apps/hawk-trial
node server.js
```

起動するとターミナルに「トライアルの URL」と「管理画面の URL（キー付き）」が出る。

### 設定（環境変数・すべて任意）

| 変数 | 既定 | 内容 |
|---|---|---|
| `PORT` / `HOST` | 8787 / 127.0.0.1 | 外から見せるときは `HOST=0.0.0.0` |
| `HAWK_TRIAL_PUBLIC_URL` | `http://localhost:8787` | 招待リンクに使う URL（公開するときの URL にする） |
| `HAWK_TRIAL_SLACK_WEBHOOK` | なし | 申込・登録の通知先（**決まったチャンネル**の Incoming Webhook） |
| `HAWK_TRIAL_GOG_ACCOUNT` | なし | 招待メールを Gmail 下書きにするアカウント（送信はしない） |
| `HAWK_TRIAL_DAYS` | 14 | トライアル日数 |
| `HAWK_TRIAL_OFFER_DEADLINE` | トライアル終了日 | 「〇〇までのお申込みで1ヵ月無料」の〇〇（例 `2026-12-04`） |
| `HAWK_TRIAL_COUPON` | `HAWK-1MONTH-FREE` | クーポンコード（**仮**） |
| `HAWK_TRIAL_EXTRACT_PER_DAY` | 30 | 1人1日の AI 読み取り上限 |
| `HAWK_TRIAL_ADMIN_KEY` | 自動生成（`data/admin_key`） | 管理画面のキー |
| `HAWK_TRIAL_MODEL` / `HAWK_TRIAL_EFFORT` | `claude-opus-5-5` / `low` | 読み取りに使うモデルと effort |

## 送信の決まり（CLAUDE.md「送信の絶対ルール」）

- 来場者へのメールは**自動送信しない**。招待メールは管理画面で文面を出すか、Gmail の下書きにするところまで
- Slack は、設定した**決まったチャンネル**への通知だけ

## まだ決めること・本番前にやること

- **利用規約はたたき台**（`pages.js` の `TERMS_BODY`）。法務確認が必要。申込書も別途
- **外部の人に使ってもらうには公開先が要る**。今の作りは「片山さんの Mac の `claude -p`」で AI を動かすので、
  展示会ブースのデモや社内確認向き。来場者に配るなら、サーバーを置く場所と、AI を Claude API（API キー）で呼ぶ形への切り替えを決める
- クーポンコード・締切日・トライアル日数は仮の値
- 見積りの数値・推定オーディエンスはトライアル用の簡易モデル（参考案件は架空のサンプル）。画面にもその旨を表示している
