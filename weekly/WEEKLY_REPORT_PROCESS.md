## 2. 書き込みの作法（Docs API）

- タブ付き Doc なので `gws docs documents batchUpdate` を使う（`gog docs write` はタブ指定不可）。
- 1バッチ内の request は **index 降順**に並べる（前方の挿入で後方の index がずれるため）。
- 表の列追加（`insertTableColumn`）と セル書き込みは**別バッチ**にし、間で `documents.get` を挟む。
- 見出し行は「1セルの表」で作られている。表を探すときは先頭セルの**完全一致**で取る（`ステータス` を部分一致で探すと見出し表を掴む）。
- 箇条書き段落の先頭に挿入すると箇条書きを継承する。ブロック追加は非箇条書き段落（例: `【確度高】`）の先頭に挿入する。
- 強調は `updateTextStyle`（`bold` + `backgroundColor`）。
- 作業用ヘルパー: `weekly/docs_helpers/`（`doclib.py` / `tablelib.py`）。

### 箇条書き階層の付け方（2026-09-17 に実測）

- `createParagraphBullets` の階層は「先頭タブ数」だけでなく、**直前の段落が箇条書きならその階層に加算**される
  （L1 の詳細行の直後に挿入したブロックは、タブ0でも L1 になる）。
- 既に箇条書きになっている段落に対しては、先頭タブがあっても階層は変わらない（タブが残る）。
- 確実に L0/L1 で作る手順:
  1. `deleteParagraphBullets` → `updateParagraphStyle` で `indentStart`/`indentFirstLine` を 0 に戻す
  2. 詳細行の先頭に `\t` を挿入
  3. ブロック先頭に **一時的な空段落**（`\n`）を入れて「直前が箇条書きでない」状態を作る
  4. 空段落を除いた範囲に `createParagraphBullets`（`BULLET_DISC_CIRCLE_SQUARE` = ●○■、既存と同じ見た目）
  5. 一時段落を `deleteContentRange` で消す
- 挿入テキストは挿入位置の段落の文字スタイル（太字・取り消し線）を継承するので、
  直後に `updateTextStyle` で `bold:false, strikethrough:false` を明示する。
- 個別商談の既存フォーマット: 見出し（【確度高】等）= 太字・非箇条書き／社名 = L0 細字／詳細 = L1 細字。
  段落内の改行は `\u000b`（ソフト改行）で入れられる（ウェビナー節の「参加アンケート／本番資料」行）。
- リンクは `updateTextStyle` の `link.url`（範囲は段落 startIndex + 文字列オフセット、UTF-16 単位）。

## 5. 週報 9.（顧客からの要望まとめ）の形式ルール（2026-09-17 確定）

- 形式は本番週報「9. その他」の現物が正。要望まとめ Doc の上部サマリーは**これと同一**に保つ（週報への転記はコピーのみ）。
- 構成: `【〇〇の部】` 見出し（太字）→ `・項目（社名、社名）… N社`（必要なら ※注記）。カテゴリ順:
  要件整理・入稿／見積もり・提案／レポート・ダッシュボード／クリエイティブ／現場運用者の使いやすさ（新設）／媒体・外部連携／料金・プラン／管理・セキュリティ。
- **太字は片山が重要と判断した項目**。自動更新で外さない・増やさない。新規行は細字。行の一部だけ太字（項目名のみ）の行もそのまま保つ。
- 日付ブロックや行頭の日付は付けない（見にくくなるため）。新着の強調が要るときは片山が手で行う。
- 括弧・句読点・改行・文字サイズは現物のまま継続。
- 週報 9. の冒頭には正本 Doc・企業マスタ・提案ステータス・議事録へのリンク行（ローデータの所在）を置く。
- 1社の声も明細（Doc 下部・No.付き）には必ず残す。サマリー掲載は2社以上、または片山が指定したもの。
