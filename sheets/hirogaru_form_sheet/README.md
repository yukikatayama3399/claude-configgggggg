# HIROGARU_フォーム入力シート_0817 / 自動追加中リスト_SNS広告求人

外部作業者が **H列(入力状況) / I列(送信日時)** に手入力できるようにするための構成。
対象: https://docs.google.com/spreadsheets/d/1gYL-_-rM52JrWEtsL-Cx-Wv4BPjS49qg9g_n2xq8WqQ/edit?gid=892888463

## 変更前の問題

`自動追加中リスト_SNS広告求人!A1` に配列数式1本（`IMPORTRANGE` + `FILTER`）が入っており、
A1:O 全体がそのスピル範囲だった。よって

- H/I もスピル範囲内なので **どのセルにも手入力できない**
- `FILTER` が「除外リスト / 配信結果csv / 全リスト / 0814 / 0817 に既出の会社」を落とすため、
  会社が処理済みになるたび行が繰り上がる。仮に H:I を数式の外に出しても
  **記入内容が1行ずつズレて壊れる**

このため「A:G と J:O に分けてスピルさせ H:I を空ける」案は採らず、作業シートを静的化した。

## 変更後の構成

| シート | 役割 |
|---|---|
| `_取込元_SNS広告求人`（隠し・保護） | 旧 A1 の `IMPORTRANGE`+`FILTER` をそのまま移設。誰も書かないので配列のままでよい |
| `自動追加中リスト_SNS広告求人` | **静的な値のみ**。H/I は普通の入力セル（黄色背景）。他は保護して編集不可 |
| `_同期ログ`（隠し・スクリプトが自動生成） | 同期の実行時刻・結果・追記件数 |

- 取込元と作業シートを会社名(B列)で突き合わせ、**未取込の行だけを追記**する。
- 追記するのは **A:G と J:O だけ**。H:I は書き込み対象から外しているので、
  入力済みの内容が上書きされることも、行がズレることも構造上起きない。
- 取込元が並べ替え・行削除されても作業シートの行は動かない。

### 保護設定（2026-08-24 適用済み）

- `自動追加中リスト_SNS広告求人`: シート全体を保護し、**H2:I のみ編集可**の例外にしている。
  オーナーは全列編集可。外部作業者は入力状況・送信日時しか触れない。
- `_取込元_SNS広告求人`: シート全体を保護。
- 外部作業者は保護範囲を並べ替えできないので、絞り込みは**フィルタ表示**（個人用）を使ってもらう。

## Apps Script のセットアップ（初回だけ・所有者アカウントで）

Apps Script API が OAuth プロジェクト側で無効なため、コードは手貼りする。

1. スプレッドシートを開く → 拡張機能 → Apps Script
2. `appsscript/同期.gs` の中身を全部貼り付けて保存
3. 関数リストから `syncNewRows` を選んで ▷ 実行 → 権限を承認（初回のみ）
4. スプレッドシートを再読み込み → メニュー **「新着取込」** が出る
5. 「⏰ 自動取込を有効化（1時間ごと）」を1回押す

メニュー:

- 🔄 いま取り込む … 手動で新着取込
- ⏰ 自動取込を有効化（1時間ごと）/ ⏹ 自動取込を停止
- ℹ 状態を確認 … 行数と自動取込の有効/無効

注意: 同期は保護列に書き込むため**所有者アカウントでのみ**成功する。
外部作業者がメニューを押すとエラーになる（無害）。

## 保守メモ

- 列を増やす場合は `LAST_COL` と `WRITE_BLOCKS` を更新する。
  取込元と作業シートのヘッダーが一致しないとスクリプトは追記せず中止する（事故防止）。
- 取込元が `#REF!` / 読込中 / 0件のときも追記せず中止する。
- 移設時に `IMPORTRANGE` の範囲を `フォーム送信用!A2:R3000` → `A2:R`（開放端）に変更した。
  取込元が3000行を超えても取りこぼさない。
- `backup/` に変更直前の値と数式のスナップショットがある（2026-08-24）。
