## ファイル

- `*_変更前.csv` … 削除前の全行（行番号付き）
- `*_削除ログ.csv` … 消した行と理由（分類: 除外リスト該当(同一法人) / 除外リスト該当(親子・グループ会社) / 重複）
- `*_削除ログ_第2弾.csv` … 第2弾で消した行と理由（行番号は第1弾後のもの）
- `*_要確認_第2弾で削除.csv` … 第1弾では残した「似ているが別法人」の行。第2弾で全部消した
- `*_削除行番号.json` … 削除した行番号
- `summary.json` … 件数のサマリ

## 判定ロジック

`../../company_match.py`（正規化照合）＋ 手動判定（社名変更・親子会社）。
社名変更・親子会社は文字列では判定できないので、削除ログの「理由」列に根拠を書いてある。
同じ照合を `sync_new_rows.py` が毎回の取込前にかけるので、消した表記は復活しない。
第2弾で消した社名のうち、文字列では判定できないもの（社名変更・親子会社・迷う先）は
`../../exclude_extra.tsv` に社名と理由を書いてある。
