## 仮予定の書き方（スキル・Routine・手作業で共通）

- 仮押さえを作るときは**タイトルに `【仮】` を付ける**（例: `[オンライン社外] 【仮】〇〇様／HAWKご説明（候補2）`）。
  色分けスイープはタイトルの仮マーカーだけで仮予定を判定する。
- 確定したら**タイトルから `【仮】` を外す**。色は次のスイープ（9:20 / 15:20）で自動で変わる
  （急ぐなら自分でオンライン=オレンジ(6)／訪問=紫(3)に塗り替えてよい）。
- スイープが仮予定とみなすタイトル（`calendar/color_sweep.py` の `is_tentative()`）:
  - `【仮】` `[仮]` `(仮)` `（仮）` `仮)` のように**仮の直後が閉じ括弧**
  - `仮押さえ` `仮押え` `仮予定` `仮日程` `仮候補`（`【仮候補】` を含む） `仮置き`
  - **タイトル先頭**（`[主タグ]` の直後を含む）の仮で、直後が漢字でないもの: `仮/ビルコム` `仮みのまた` `仮[往訪] …` `仮 〇〇様`
  - ただし `確定` を含むもの（`【仮→確定】` 等）は仮予定にしない
- 仮予定にならない（誤検知しない）例: `[作業] 仮枠整理` `仮説検証` `仮想通貨` `（仮称）`

## 命名（主タグ）との対応

命名Routineが付ける主タグは7つのみ: 往訪 / 来訪 / オンライン社外 / 社内 / オンライン社内 / 作業 / Private。
**これ以外のタグを発明しない**（[オフライン社内]のような変種を作らない。対面の社内MTGは[社内]）。
仮予定は主タグとは別に、タイトルの `【仮】` で表す（`[仮]` という主タグは作らない）。

| 主タグ | 色 | availability |
|---|---|---|
| どの主タグでも、タイトルに `【仮】` 等の仮マーカーがあるもの | **黄 5（最優先）** | 主タグどおり |
| [作業]（[準備]も作業扱い） | グレー 8 | FREE |
| [オンライン社外] [オンライン社内] | オレンジ 6 | BUSY |
| [往訪] [来訪] [社内]（過去の変種 [社外] [オフライン*] も同じ） | 紫 3 | BUSY |
| [Private] 外出系（ランチ・会食・飲み・通院・ジム等） | 紫 3 | FREE |
| [Private] その他・関係ないもの | 赤 11（=既定色のまま） | FREE |

タグが無い予定はスクリプトがキーワード・出席者から推定する（推定は必ず報告に出る）:
- 外出キーワード（ランチ/会食/飲み/通院/ジム…）→ 紫
- タイトルに「オンライン」等 → オレンジ
- 他の出席者がいる → 紫（対面に倒す）
- 「準備」「メモ」等の作業キーワード → グレー
- 会議らしいタイトルだが対面/オンライン不明 → **触らず要タグ付けとして報告**
- 推定でグレーにしようとした予定に既に黄/オレンジ/紫が付いている → **触らず報告**（手動の意図を尊重）

## 実行の仕組み（Routine 2本立て）

1. **カレンダー命名＆予定あり/なし仕分け**（毎日 9:00 / 15:00 JST, MCPコネクタ使用）
   タイトルに主タグを付け、availability を直す。色は触らない。`【仮】` は消さない。
2. **カレンダー色分けスイープ**（毎日 9:20 / 15:20 JST, gog使用）
   命名の直後に走り、仮マーカーとタグに従って色だけを塗る。
   判定は `calendar/color_sweep.py`（このリポジトリが正本）が決定論的に行う。
   Routine は実行のたびに `claude/fervent-keller-khdqe9` ブランチからこのスクリプトを取り直して使う
   （ブランチを変えたら Routine のプロンプトの取得元も直す）。

手動で回す場合（このリポジトリのクローン内で）:

```bash
python3 calendar/color_sweep.py           # ドライラン（読み取りのみ）
python3 calendar/color_sweep.py --apply   # 適用（書き込み後に読み返し検証）
```

## 判定に使ってよい材料・いけない材料

- ✅ タイトルの仮マーカー（`【仮】` 等）、タイトル先頭の `[主タグ]`、タイトル中のキーワード
- ❌ Meetリンク・会議室リソース・location（2026-08-22 実測で、
  会議室を押さえていてもオンライン／Meetリンクがあっても対面のケースが両方ある）
