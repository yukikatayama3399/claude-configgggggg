# あゆみのほけん相談室 — 過去キャンペーン実績サンプル 10件

見積もり時の「再参照案件」候補リストを増やすための、
株式会社あゆみのほけん相談室のダミー実績データです。

## ファイル

| ファイル | 用途 |
|---|---|
| `ayumi_campaign_samples.tsv` | **スプレッドシートに貼る用**。全選択してコピー → スプレッドシートのA1に貼れば列が揃う |
| `ayumi_campaign_samples.json` | エンジニア投入用。1件=1レコード |
| `generate.py` | 生成スクリプト。件数追加・数値の再調整はここを直して再実行 |

`python3 generate.py` で TSV と JSON を再生成し、集計サマリを標準出力に出します。

## 内訳

- 全10件 / 広告アカウントは全て「あゆみのほけん相談室」
- 目的: **リード 5件 / 認知 5件**
- 配信期間: 2025/01 〜 2026/05（既存の `あゆみのほけん相談室_無料相談リード_2507` より過去に収まるよう配置）
- キャンペーン名の末尾 `_YYMM` は配信開始年月（既存の命名規則に合わせた）

## 数値の着地点

| 区分 | 加重クリック率 | 加重CPM | 消化額 平均 | 消化額 レンジ |
|---|---|---|---|---|
| リード 5件 | **1.34%** | ¥769 | ¥1,524,000 | ¥1,090,000 〜 ¥2,150,000 |
| 認知 5件 | **0.60%** | ¥394 | ¥1,476,000 | ¥1,010,000 〜 ¥2,480,000 |
| 全10件 | 0.86% | ¥524 | **¥1,500,000** | ¥1,010,000 〜 ¥2,480,000 |

「加重」= インプレッション加重平均。既存UIの平均行が
`合計クリック ÷ 合計imp` / `合計消化額 ÷ 合計imp × 1000` で出しているのに合わせています。

目的によるクリック率の差（リード/売上は高め、認知は低め）は、
リード系 1.12〜1.54%、認知 0.50〜0.69% のレンジでばらつかせた上で
それぞれ 1.34% / 0.60% に着地するよう配分しています。

## 各行が満たしている整合ルール

全10行が以下を厳密に満たします（丸め誤差ゼロを検証済み）。
候補を追加するときも必ずこの関係を崩さないこと。

```
消化額       = imp × CPM ÷ 1000
クリック     = imp × クリック率
リーチ       = imp ÷ フリークエンシー
```

TSV/JSON の CPM・クリック率・フリークエンシーは、
imp とクリック等の実数から**逆算し直した表示値**なので、
UIでそのまま再計算しても数字が合います。

## カラム定義

| TSV列 | JSONキー | 型 | 備考 |
|---|---|---|---|
| 広告主 | `advertiser` | string | 「株式会社あゆみのほけん相談室」 |
| キャンペーン名 | `campaign_name` | string | |
| 広告アカウント | `ad_account` | string | UIの「カテゴリ」列に出ている値 |
| 目的 | `objective` | enum | `リード` / `認知`（既存の他値: `売上` / `トラフィック`） |
| imp | `impressions` | int | |
| CPM | `cpm` | int | 円 |
| クリック | `clicks` | int | |
| クリック率 | `ctr` | number | JSONは `1.12` = 1.12%（%記号なし）。TSVは `1.12%` |
| リーチ | `reach` | int | |
| フリークエンシー | `frequency` | number | 小数2桁 |
| 消化額 | `spend` | int | 円 |
| 配信開始 | `start_date` | string | `YYYY/MM/DD` |
| 配信終了 | `end_date` | string | `YYYY/MM/DD` |
| 配信期間 | — | string | 表示用に `開始〜終了` を連結したもの。JSONには持たせていない |

## 既存行との関係（要確認）

既存の `あゆみのほけん相談室_無料相談リード_2507`（imp 1,436,170 / クリック率 1.54% /
消化額 ¥1,093,500 / 2026-07-10〜2026-08-09）はそのまま残す前提で、
上記10件とは別枠です。この既存1件を含めてリード系6件で加重平均を取ると **1.37%** になり、
1.34% からわずかに上振れします。プール全体で 1.34% に揃えたい場合は
`generate.py` のクリック率を再配分してください。
