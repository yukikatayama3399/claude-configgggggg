# HAWK 参考案件プール用サンプル実績データ — 4アカウント × 10キャンペーン = 40行

見積もり提示時に「参考案件」の候補から選ぶ（ぽちぽち選ぶ）ための、ダミー実績データ。
既存サンプルは1アカウント1キャンペーンしか無く「選ぶ」体験にならないため、
**同一広告アカウントの中に複数キャンペーンが並ぶ状態**を作るのが目的。

**納品スプレッドシート**:
https://docs.google.com/spreadsheets/d/1I3ZjefKj2X2mVfjbj5rn2Xf0h9D-1xfjLtc6wWLtYJg/edit
（`campaigns` / `集計` / `README` の3タブ）

## ファイル

| ファイル | 用途 |
|---|---|
| `campaign_samples.tsv` | スプレッドシート貼付用。全選択してコピー → A1に貼れば列が揃う |
| `campaign_samples.json` | エンジニア投入用。1件=1レコード |
| `generate.py` | 生成スクリプト。件数追加・数値の再調整はここを直して再実行 |

`python3 generate.py` で TSV と JSON を再生成し、アカウント別サマリを標準出力に出します。

## 数値設計の考え方

1. **クリック率は「目的」で決まる。** 同じ目的なら社が違ってもだいたい同じ水準に着地させている。
   認知 0.60% / トラフィック 1.42〜1.89% / 売上(CV) 1.32〜1.34% / リード 1.34%
2. **CPM と消化額は「その社の既存参考キャンペーン行」に寄せている。** 社ごとに水準が違う。
3. **動画は静止画よりフリークエンシーを高め**（1.9〜3.2）に振っている。静止画は 1.3〜2.5。

「加重」= インプレッション加重平均。既存UIの平均行が
`合計クリック ÷ 合計imp` / `合計消化額 ÷ 合計imp × 1000` で出しているのに合わせています。

あゆみのみクリック率が既存行より低い（1.54% → 1.34%）のは、
リード系は 1.34% に着地させるという先の指定を優先しているため。
あゆみの消化額平均 ¥1,500,000 も先の指定（100万〜300万・平均150万）をそのまま据え置いている。

**アクアリーフ飲料は既存の参考行が手元に無いため、動画×飲料の相場で設計している。**
実データがあればその水準に寄せ直せる。

## 各行が満たしている整合ルール

全40行が以下を厳密に満たします（丸め誤差ゼロを検証済み）。
候補を追加するときも必ずこの関係を崩さないこと。

```
消化額       = imp × CPM ÷ 1000
クリック     = imp × クリック率
リーチ       = imp ÷ フリークエンシー
```

TSV/JSON の CPM・クリック率・フリークエンシーは、
imp とクリック等の実数から**逆算し直した表示値**なので、
UIでそのまま再計算しても数字が合います。

## カラム定義

| TSV列 | JSONキー | 型 | 備考 |
|---|---|---|---|
| 広告主 | `advertiser` | string | 正式名（株式会社付き） |
| キャンペーン名 | `campaign_name` | string | 40件すべてユニーク |
| 広告アカウント | `ad_account` | string | UIの「カテゴリ」列に出ている値 |
| 目的 | `objective` | enum | `リード` / `認知` / `売上` / `トラフィック` |
| クリエイティブ形式 | `creative_format` | enum | `静止画` / `動画`（今回追加した列） |
| imp | `impressions` | int | |
| CPM | `cpm` | int | 円 |
| クリック | `clicks` | int | |
| クリック率 | `ctr` | number | JSONは `1.12` = 1.12%（%記号なし）。TSVは `1.12%` |
| リーチ | `reach` | int | |
| フリークエンシー | `frequency` | number | 小数2桁 |
| 消化額 | `spend` | int | 円 |
| 配信開始 | `start_date` | string | `YYYY/MM/DD` |
| 配信終了 | `end_date` | string | `YYYY/MM/DD` |
| 配信期間 | — | string | 表示用に `開始〜終了` を連結。JSONには持たせていない |

## 既存行との関係（要確認）

既存の参考行3件（`あゆみ_2507` / `つきしろ_2507` / `たびそよぎ_2606`）はそのまま残す前提で、
この40行とは**別枠**です。つまり残すとその3アカウントは11件になります。
ちょうど10件にしたい場合は既存行を落とすか、この40行から1件ずつ間引いてください。

なお `ソヨカゼモバイル` は当初の候補に挙がっていましたが、
最終的な4社（あゆみ / つきしろ / アクアリーフ / たびそよぎ）の整理で対象外としています。
