## 手順
### 1. 当週のアクション列を特定
当週の月曜＝「実行日−3日」。ラベル `M/D週`（先頭ゼロなし。例 6/29→`6/29週`）。
`gog sheets get 1iyhwVNhN_HJNdIBL_pREhrhBdQu2it5ktFOYq-DDm_w "提案ステータス!1:1" -a yuki.katayama@fout.jp -p` を読み、G列以降で `M/D週` に**完全一致**するセルの列を「当週列」とする。
**一致が無い場合**：書き込まず、Slackに「⚠️ 当週列(`M/D週`)が未作成。区分列を壊さないため自動追加はしない。手動で週列を1つ追加して」とだけ通知して終了。

### 2. Yuki行を取得
`gog sheets get 1iyhwVNhN_HJNdIBL_pREhrhBdQu2it5ktFOYq-DDm_w "提案ステータス!A1:N80" -a yuki.katayama@fout.jp --json --results-only`
ヘッダ行で各列indexを確定。**B列(担当)が `Yuki`** の行だけ対象に、行番号・A(社名)・C・D・当週列の現在値を控える。avex/REGALCORE等はスキップ。

### 3. 今週の活動を集める（議事録＋カレンダー）
当週の月曜00:00〜木曜実行時刻(JST)を「今週」とする。
(a) **議事録Doc**：`gog drive search "(name contains '議事録' or name contains '商談' or name contains 'meet' or name contains '打ち合わせ' or name contains '打合せ' or name contains 'メモ') and modifiedTime > '<今週月曜のISO8601>' and trashed = false" --max 80 -a yuki.katayama@fout.jp --json --results-only`。所属会社をYuki行の社名(正規化)でタイトル突合。確信あるものだけ紐づけ、本文を `gog docs export <docId> -a yuki.katayama@fout.jp --format md` で読み事実抽出。
(b) **カレンダー**：今週(月〜木)の商談を取得(`gog calendar events` 等)。Yuki行の社名に紐づく外部アポを拾う。議事録が無い接触もカレンダーの事実(日付・形態・出席者)だけ当週列に短く記録。

### 4. 当週列の文面を作る（行ごと）
活動が1件以上あるYuki行のみ。
- **既存の当週列セルの内容は一つも失わず取り込み**、議事録・カレンダーで**増補（高密度化）**。上書きで情報を削らない。
- 文頭は `M/D 形態:`（例 `6/30 meet:`）。複数接触は改行で複数行。粒度基準を満たす。憶測禁止。
- **議事録リンク化（必須）**: 紐づく議事録Docが特定できた行は、当週列セル全文を `=HYPERLINK("https://docs.google.com/document/d/<docId>/edit","<高密度テキスト>")` の数式にする（表示テキストは削らない）。特定できない行はプレーンのまま。複数商談は主となる1本にリンク。

### 5. ステータス(C)・NA(D)の更新（根拠があるときだけ）
- C: 議事録に明確な遷移根拠があるときだけ語彙内で更新（対象外/見送り/予算なし→`失注`、導入決定/連携完了→`1_導入済`、検討中/持ち帰り→`4_商談中（先方検討中）`、日程確定・案内実施で前進→`5_開始`）。曖昧なら変えない。
- D(NA): 読める次アクションを簡潔更新。読めなければ変えない。
- C/Dを変えた行は旧値→新値をSlack通知に必ず列挙。

### 6. 失注理由(N)の記入（担当=Yuki かつ C=失注 かつ N空の行）
当週変更行に限らず、手順2のYuki行全体で C=`失注`（今回失注化した行含む）かつ N空の行すべてを対象。根拠は当週追記/既存のNA(D)・当週列の事実(議事録・カレンダーのみ・憶測禁止)。1〜2文で要約(日付プレフィックス不要)。既にNに値がある行は上書きしない(冪等)。根拠不足で要約できない行は空のまま残しSlackに「⚠️失注理由が根拠不足で未記入」として社名列挙。

### 7. シートへ直接書き込み（RAW・改行/カンマ安全）
変更のある行・セルだけを `gog sheets batch-update 1iyhwVNhN_HJNdIBL_pREhrhBdQu2it5ktFOYq-DDm_w --data-json @<tmpfile> --input RAW -a yuki.katayama@fout.jp` でまとめて更新。手順6のN列書込もこのバッチに含める。
- データは一時JSONに書く（本文に改行・カンマ・引用符が入るため引数直書き禁止）。例：`[{"range":"提案ステータス!J21","values":[["6/30 meet: …\n7/2 電話: …"]]},{"range":"提案ステータス!C25","values":[["失注"]]},{"range":"提案ステータス!N25","values":[["自社AIチームで運用改善中。…"]]}]`
- `--input RAW` を使う（日付自動変換を防ぐ）。
- **リンク化した当週列セル（`=HYPERLINK(...)`）だけは別扱い**：`--input USER_ENTERED` の別バッチで書く（プレーン=RAW、リンク=USER_ENTERED＝2回に分ける）。数式はpythonで組み、表示テキスト中の `"` は `""`、改行は `"&CHAR(10)&"` で連結。RAW/USER_ENTEREDを同一バッチにしない。
- **本番前は必ず確認**：初回・挙動変更時は書込せず「どのセルに何を書くか」をSlackに列挙し本人確認してから本運用。
- 書込後 `gog sheets get` で対象セルを読み返し自己検証。空・無反応を成功とみなさない。リンクセルは `gog sheets links <sid> "提案ステータス!J<row>"` で表示テキスト欠落も確認。

### 8. Activity集計シートの片山ブロックを更新（件数）
(a) 当週列特定：`gog sheets get 1S5EB3iEhx3P97_YE6Yx8Kxm_Fwao2Xo_pIpxCaqSB8k "Activity!11:11" -a yuki.katayama@fout.jp -p` を読み `M/D週` に**完全一致**する列を当週列に（一致無ければActivityスキップ＋Slackに「⚠️Activity当週列未作成」）。**必ず行11で列を取る**（片山ブロックは C=6/15週 始まり）。
(b) **商談・デモ実施**（当週列の17/18/19。B列ラベルで照合）：今週(月〜木)カレンダーで**実施した**商談/デモ/往訪/来社/meet/オンライン説明の外部アポを数え、クライアントを提案ステータスで突合し「In or Out」→区分マッピングでバケツ分け。社内・avex・REGALCORE・個人は除外。
(c) **初回接触**（当週列の13/14/15。B列ラベルで照合）：今週「初めて接触した先」をソース別に。①送信済みGmail（当週のHAWK初回案内メール宛先＝初回接触。同一先複数通は1件）②`1_ad_info`当週新規行＝インバウンド③「Yuki」タブ(gid=720560865)当週初回架電。振り分け：ad_info新規/OEM休眠架電→休眠・インバウンド、紹介経由→紹介、info@コールド発で反応取れた先→コールド(info@)。重複排除。**自動判定は精度が落ちるため内訳をSlackに必ず出す**。数えられなければ空のまま「初回接触は要手入力」と添える。
(d) 書込：`gog sheets batch-update 1S5EB3iEhx3P97_YE6Yx8Kxm_Fwao2Xo_pIpxCaqSB8k --data-json @<tmpfile> --input RAW -a yuki.katayama@fout.jp` で**片山ブロック当週列の6セル(13/14/15/17/18/19行)のみ**を数値更新。0件も `0` を明示。**他ブロックは一切触らない**。書込後 `gog sheets get` で6セル読み返し検証。

### 8.5 来週の重点商談リスト（定例会報告書Doc貼り付け用）
来週(実行日翌週の月〜金)のYukiカレンダーから外部HAWK商談・案内アポを抽出：`gog calendar events yuki.katayama@fout.jp --from <翌週月曜> --to <翌週土曜> -a yuki.katayama@fout.jp -p`。対象=`[オンライン社外]`/`[社外]`/`往訪`/`来訪`/`来社`、`[社内]〜HAWK案内` 等。除外=REGALCORE/個人/`[作業]`/社内定例。未確定調整ブロックは「日程調整中」と付記。形式：各行 `* <社名>（Yuki[／補足]）：M/D(曜) HH:MM <形態・内容>`（曜日は`date`照合）。**共有Docへ自動書込せず、下のSlackに「貼り付け用ブロック」として出すだけ**。定例会Doc: `1I7u2zNZTPl9tAo2SGalo35ElsDWu2MPpP6JgIYr8LCk`。
