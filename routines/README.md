# クラウド Routine（定期実行）

Mac ローカルの scheduled-tasks から**クラウド Routine へ移した**ものを置く。
クラウド Routine は Mac のスリープ・Claude Code の起動状態と無関係に発火する。

## なぜ移したか

Mac ローカルの定期タスクは `scheduled-task-routine` スキルに書いてあるとおり
**「Claude Code 起動中にのみ発火する」**。実際に
`Hawk proposal status digest` / `Daily calendar color coding` の2つが
「開始できませんでした。手動で実行してみてください」で落ちた（2026-08-22）。
同時刻のクラウド Routine は全て正常発火していたので、原因は Mac 側の可用性。

## 現在のクラウド Routine（このリポジトリ由来のもの）

| Routine | cron (UTC) | JST | 中身 |
|---|---|---|---|
| HAWK提案ステータス 日次ダイジェスト | `30 0 * * 1-5` | 平日 9:30 | ヨミ管理シートを読んで内訳・停滞を通知（**読み取り専用**） |
| カレンダー色分けスイープ | `20 0 * * *` | 毎日 9:20 | `color_sweep.py` を実行して予定の色だけ更新 |

色分けは命名ルーティン（毎日 9:00/15:00 JST）がタイトルに `[主タグ]` を付けた後に走る想定。

## 定期実行セッションの制約（毎回ここで転ぶ）

1. **リポジトリがクローンされない。** SessionStart フックが動かないので `gog` が入っていない。
   各 Routine のプロンプト冒頭に gog ブートストラップのブロックを必ず入れる。
2. **シェルの状態が引き継がれない。** 全 bash 呼び出しの先頭で `export PATH="$HOME/bin:$PATH"`。
3. **MCP コネクタが載らない。** `create_trigger` の MCP 経由で作った Routine は
   `mcp__Slack__*` などが使えない（実測: 2026-08-22 のテスト発火で Slack 送信不可）。
   そのため通知は「Slack があれば Slack、無ければ gog で自分宛メール」の二段構えにしてある。
   Slack を確実に使いたい場合は claude.ai の Routines UI から作り直してコネクタを紐づける。

## color_sweep.py

4バケツで色を付ける。判定は決定論（LLM の裁量を挟まない）。

| バケツ | 対象 | colorId |
|---|---|---|
| 作業 | `[作業]` タグ、またはタグ無し＆出席者なし | 8 グラファイト |
| meet | `[オンライン*]` タグ、またはタグ無し＆Meetリンクあり | 6 タンジェリン |
| 対面 | `[往訪]/[来訪]/[社内]/[社外]` タグ、またはタグ無し＆出席者あり＆Meetなし | 11 トマト |
| デフォルト | `[Private]` タグ、または私用キーワード | 色を付けない |

タグがあればタグを優先し、無いときだけ出席者・Meet リンクから推定する。
推定したぶんは必ず報告に出す（人が見て直せるように）。

触らないもの: 終日予定 / 勤務場所イベント(オフィス・在宅・自宅) / キャンセル済み / 未知のタグ。

```bash
python3 routines/color_sweep.py            # ドライラン（読み取りのみ）
python3 routines/color_sweep.py --apply    # 適用 + 読み返し検証
```

初回スイープは 2026-08-22 に実行済み（20件適用、うち18件反映・2件は下記バグで未反映）。
