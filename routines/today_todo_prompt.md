## 絶対に守ること
- 読み取りが基本。書き込んでよいのは Google カレンダーに「[作業] 今日のToDo」という予定を1つ新規作成することだけ。既存の予定の変更・削除は、同名の予定も含めて一切しない。
- メール送信・Slack 投稿・リアクションは一切しない。gog は必ず `--gmail-no-send` を付けて使う。

## 2. 2つのブロックに分けて並べる（絞らない）
- **件数で切らない。** 本人がやる必要がありそうなものは全部載せる。迷ったら載せる（閉じてよいのは上の「完了」「FYI のみ」「他の人が片付けた」「引き継ぎ済み」だけ）。
- 同じ件（同じ相手・同じ用件の Slack とメールなど）は1件に統合し、URL は代表の1本＋必要なら2本目まで。同じ件を2つのブロックに重ねて書かない。
- 「今日やること」: 対象日の予定・作業枠、期限が今日のもの、すでに相手を待たせている返信・依頼、未送信の下書き、期限を過ぎたもの。並び順: 期限が今日 > 社外の相手 > 放置日数が長い > 特定の人からの直接依頼 > cc 型・FYI 寄り。
- 「向こう1週間の準備」: 向こう7日の商談・期限に向けて、今日以降に用意しておくこと。日付の近い順に並べ、各項目の頭に対象の日付と予定名を書く。
- 長くなりすぎないよう、説明文全体はおよそ 7000 文字以内に収める。超えそうなときは並びの後ろから削り、末尾に「ほか N 件は省略（<取得元>）」と書く（黙って落とさない）。

## 3. カレンダーに書く
次の形のコマンドを単独で1回だけ実行する（許可設定に一致させるため、先頭からこの順のまま。`&&` `;` `|` `$(...)` や事前の `cd`・`source`・`export` を付けない。説明文はファイル経由ではなく、ダブルクォートの中に直接書く）:
```
gog --account yuki.katayama@fout.jp --gmail-no-send -j calendar create primary --summary "[作業] 今日のToDo" --from <対象日>T09:00:00+09:00 --to <対象日>T09:15:00+09:00 --send-updates none --transparency transparent --description "<説明文>"
```
説明文の形式（プレーンテキスト、各行は短く。手書きノートに写しやすいように。ダブルクォートと $ と ` は使わない）:
```
■ 今日やること
□ 1. <やること>（<相手>・<期限 or 経過日数>）
   <一言メモ: いまの状況や次の一手を1行で>
   <元のスレッド/メール/予定へのURL>
□ 2. ...
（件数の上限なし。了解済みで作業が残っているものは「作業: 〜・👍済」と書く）

■ 向こう1週間の準備（<翌日の M/D>〜<7日後の M/D>）
□ 1. <M/D(曜)> <予定名や期限>：<準備すること>（<相手>）
   <一言メモ: なにを・いつまでに用意するか>
   <予定・スレッド・メールへのURL>
□ 2. ...
（準備が要るものがなければ「なし」と1行だけ書く）

生成: <時刻> / 今日 <件数>件・準備 <件数>件 / Slack <件数>（完了で閉じた <件数>・了解済み <件数>）・Gmail <件数>（下書き <件数>）・カレンダー 今日 <件数>・向こう7日 <件数> を確認 / 引き継ぎ済みで除外 <件数>
判断に迷ったスタンプ: <あれば :名前: を並べる。なければこの行は省く>
```
- 番号はブロックごとに 1 から振り直す。
- このコマンドが権限確認で止められた・拒否された場合は、`--summary` だけを `"[作業] 今日の5件"` に変えた同じコマンドを1回だけ実行する（こちらは許可設定に登録済み）。その場合は報告に「旧名で作成」と書く。
- 「ほかの候補」欄は作らない（全部を番号付きの本リストに入れる）。
- 一言メモは「〜の返信待ちで止まっている」「13時の商談前に確認」「金曜締切」のように、見ればすぐ動ける内容にする。
- Slack のリンクは permalink、Gmail は https://mail.google.com/mail/u/0/#all/<threadId>（下書きもそのスレッドの threadId で）、カレンダーは htmlLink。
- Slack のリンクは検索結果などに出た permalink をそのまま使う。DM やグループDM の permalink が手元に無いときは、チャンネルIDを推測で組み立てず、URL 行に「Slack: <相手の名前>とのDM」と書く（別のチャンネルを指すリンクにしない）。
- どこかの取得が失敗したら、説明文の末尾に「⚠ <取得元> が取得できませんでした」と書く（黙って欠落させない）。
